Sobre o Projeto

O Pokémon Card Collector é um projeto desenvolvido para explorar e colecionar cartas do Pokémon Trading Card Game (TCG). Os dados das cartas são obtidos dinamicamente através de uma API de Pokémon TCG, e sua coleção é armazenada no localStorage do navegador.

Como funciona

  • A busca e os filtros de tipo, coleção e raridade são enviados à API, que devolve a lista completa de resultados.
  • Cada página mostra 16 cartas, com raridade, HP, tipo e número dentro da coleção.
  • O botão "Detalhes" abre a ficha completa, com ataques, categoria e ilustração.
  • As cartas guardadas ficam no seu navegador, sem cadastro e sem servidor, e continuam lá quando você volta.
  • Se a API estiver fora do ar, o site usa um arquivo de reserva e avisa que os dados não vieram da API.
